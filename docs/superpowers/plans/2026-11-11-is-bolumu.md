# Deep Space Log iş bölümü, Shorts departmanı ve YouTube uzmanı: uygulama planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Görev hattını denetim kilitli istasyonlara bölmek, ajanları tanımlamak, uzun videoyu ve Shorts'u Seyir Defteri
modunda üretmek, Shorts'u bir kurgucu ajanın planıyla kesmek ve vidIQ bütçesi kodla korunan bir YouTube uzmanı kurmak.

**Architecture:** Yeni `deepspace/is_kaydi.py` istasyon listesini, çıktı dosyalarını, sha256 kayıtlarını ve kilidi tutar.
`gorev.py` komutları çalışmadan önce bu kilidi sorar (çıkış 3). Ajanlar `.claude/agents/*.md` dosyalarıdır. vidIQ
çağrıları proje `PreToolUse` kancasıyla (`deepspace/vidiq_butce.py`) izin listesi ve aylık tavana bağlanır. Shorts
mantığı `deepspace/shorts.py`'ye taşınır; dikey kare `defter.SeyirDefteri`'nin dikey düzeniyle çizilir.

**Tech Stack:** Python 3 (numpy, Pillow, ffmpeg), pytest, Claude Code alt ajanları ve kancaları, vidIQ MCP.

**Spec:** `docs/superpowers/specs/2026-11-11-is-bolumu-design.md`

## Global Constraints
- Sıra kuralı (CLAUDE.md): önce `SOZLESME.md`, sonra test, sonra kod. Her görevden sonra `py -m pytest -q` yeşil.
- Sahiple Türkçe; kanal metinleri İngilizce. Kod adları Türkçe (mevcut düzen). Kodda model kimliği yazılmaz.

- Kilit çıkış kodu **3**; kapı kırmızısı mevcut kod **2**/**1** olarak kalır.

- 3. turda da KALDI olan istasyon durumda `sefte` görünür.
- Shorts: 1080×1920, ≤60 sn, plan aralığı 20–58 sn, kanca ≤3 kelime, 3 Short 3 ayrı parçadan; ilk 2 sn ses duyulur.
- Telefon kuralı: en küçük yazı kare yüksekliğinin %2'si (`defter.EN_KUCUK_YAZI_ORANI = 0.02`).
- vidIQ: çağrı başı 5 kredi, `vidiq_balance` ücretsiz; aylık tavan `ayar.toml [vidiq] aylik_kredi = 100`; dönem
  `yenileme_gunu = 27`'de başlar. Defter `deepspace/buyume/vidiq_harcama.jsonl`.

**Interfaces:**
- Consumes: `ortak.KOK`, `ortak.MARKA_DOSYASI`, `ortak.ayar_yukle()`, `kapilar` fonksiyonları.
- Produces:
  - `ISTASYONLAR: list[str]` (Global Constraints sırası).
  - `CIKTILAR: dict[str, list[str]]`: görev klasörüne göre glob kalıpları —
    `arastirma: ["buyume/oneriler.json", "buyume/arastirma.md"]`, `konsept: ["gorev.toml", "SUNO.md"]`,
    `bilgi: ["bilgi_kaynak.json"]`, `ses: ["cikti/bolumler.json", "cikti/ses.m4a"]`,
    `gorsel: ["gorsel/[0-9][0-9].png", "denetim/[0-9][0-9].json"]`, `hareket: ["gorsel/*_hareket.json"]`,
    `video: ["cikti/video.mp4"]`, `shorts: ["shorts_plan.json", "cikti/short_?.mp4"]`,
    `paket: ["cikti/kapak_?.jpg", "cikti/youtube.json", "cikti/aciklama.txt"]`, `karar: ["cikti/onay.json"]`.
    `marka` kanal düzeyindedir: `deepspace/marka/*` (alt klasör `taslak/` hariç) ve `marka.toml`.
  - `class KilitHatasi(Exception)`.
  - `marka_ozeti() -> str`: marka dosyalarının birleşik sha256'sı.
  - `ozetler(klasor: Path | None, istasyon: str) -> dict[str, str]`: göreli yol → sha256 (`marka` için klasör None).
  - `kayit_yolu(klasor: Path | None, istasyon: str) -> Path`: `<görev>/denetim/istasyon_<ad>.json`;
    marka için `deepspace/marka/istasyon_marka.json`.
  - `kayit_oku(klasor, istasyon) -> dict | None`: bozuk JSON'da `None`.
  - `kayit_yaz(klasor, istasyon, karar: str, denetci: str, bulgular: list[dict], kirmizi: list[str]) -> Path`:
    karar `"GECTI"` ya da `"KALDI"`. GEÇTİ'de `kirmizi` doluysa ya da `ozetler` boşsa `KilitHatasi`. `tur`, önceki
    kaydın turu +1 (ilk kayıt 1). Kayıt alanları: `karar, tur, denetci, ozetler, marka_ozeti, bulgular, zaman`
    (bulgu: `{"kod", "not", "kanit"}`).
  - `sahip_onayi_yaz(kim: str) -> Path`: marka kaydına `{"sahip_onayi": {"kim", "zaman", "marka_ozeti"}}` ekler;
    marka kaydı GEÇTİ değilse `KilitHatasi`.
  - `gecerli_mi(klasor, istasyon) -> tuple[bool, str]`: kayıt var, GEÇTİ, özetler bugünküyle aynı; görev
    istasyonlarında `marka_ozeti` güncel; marka'da ayrıca güncel özetli `sahip_onayi` var.
  - `kilit(klasor: Path, istasyon: str, gorev_no: int) -> tuple[bool, str]`: `gorev_no < kilit_baslangic` ise
    `(True, "kilit dışı")`; değilse listede kendinden önceki her istasyon `gecerli_mi`.
  - `durum(klasor: Path) -> dict`: `{"istasyonlar": [{"ad", "karar", "tur", "gecerli", "neden", "sefte"}],
    "siradaki": str | None}`; `sefte = karar == "KALDI" and tur >= en_cok_tur`.
  - `kapi_kontrolleri(gorev: dict, ayar: dict, istasyon: str) -> list[dict]`: konsept → `kapilar.gorev_dosyasi`;
    ses → `kapilar.ses`; gorsel → `kapilar.gorseller`; hareket → `kapilar.hareket` (Task 7); video →
    `kapilar.video`; shorts → `kapilar.shorts` + `shorts.plan_kontrol` (Task 10); paket → `kapilar.kapak` +
    `kapilar.metin`; diğerleri `[]`.
